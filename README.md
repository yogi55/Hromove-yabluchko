# Громове яблучко (сайт)

Статичний сайт: HTML, CSS, JS без збірки. Увесь вміст у `content.json`.

## Структура
- `content.json` — 31 частина: заголовок, текст, шлях до картинки, шлях до звуку (для кожної мови).
- `img/01.jpg … 31.jpg` — ілюстрації (зараз є лише тимчасова 01).
- `audio/ua/01.mp3 … 31.mp3` — озвучка (зараз тестові тони).
- `audio/ua/01.json …` — форма хвилі для кожного mp3.

## Як замінити вміст
1. Поклади картинки в `img/` і впиши шлях у поле `img` частини (`"img": "img/02.jpg"`). `null` показує темну заглушку.
2. Поклади mp3 у `audio/ua/` під тими самими іменами.
3. Згенеруй хвилі: `python3 tools/make_peaks.py audio/ua` (потрібен ffmpeg). Без цього сайт малює тимчасову хвилю.
4. Впиши тексти й назви в `content.json`. Абзаци розділяй порожнім рядком (`\n\n`). Перший абзац отримує буквицю.

## Англійська
У `content.json` додай `"en"` у `meta.langs`, у кожну частину поле `title.en`, `text.en`, `audio.en`, а mp3 поклади в `audio/en/`. У кутку зʼявиться перемикач UA / EN.

## Локальний перегляд
`python3 -m http.server 8000`, потім http://localhost:8000 (через file:// не працює завантаження content.json).

## Деплой на Cloudflare Pages
1. dash.cloudflare.com → Workers & Pages → Create → Pages → Upload assets.
2. Назви проєкт, перетягни всю папку сайту (або zip), Deploy.
3. Адреса буде `назва.pages.dev`. Власний домен: Custom domains у налаштуваннях проєкту.
Оновлення: зайти в проєкт → Create deployment → знову завантажити папку.

## Посилання на частину
`адреса/#12` відкриває дванадцяту частину.

## Керування
Стрілки ← → на клавіатурі, свайп на телефоні, шкала внизу, клік по хвилі для перемотування, пробіл для звуку.
Після завершення озвучки сайт сам переходить до наступної частини й продовжує грати.

## Телефон
Ширина до 720 px вмикає мобільний вигляд. На початку ілюстрація велика, під нею видно початок тексту, плеєр закріплений унизу.
Коли гортаєш вниз, ілюстрація плавно зменшується, під нею проявляється заголовок, зверху зʼявляються стрілки й лічильник, текст виїжджає між ними. Гортаєш вгору, і ілюстрація знову росте.
Лічильник зверху відкриває список усіх частин. У кінці сторінки є «Попередня / Усі історії / Наступна». Перехід між частинами у згорнутому стані лишає сторінку згорнутою.
Відступи й розміри задає блок `@media (max-width: 720px)` у `css/style.css`, а проміжні розміри рахує функція `measure()` у `js/app.js`.
